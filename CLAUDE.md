## Описание проекта

Telegram-бот для отслеживания времени работы над задачами (time tracker). Пользователи могут создавать таймеры, запускать/останавливать их, создавать под-таймеры (sub-timers) для детализации времени, и получать статистику. Данные хранятся в SQLite (`timers.db`).

## Запуск и управление

**Запуск бота:**
```bash
python bot.py
```

**Запуск через bat-файл (Windows):**
```bash
TaskTrekerMaster.bat
```
Bat-файл работает как toggle: запускает бота если он не запущен, останавливает если запущен.

**Переменные окружения:**
Создать `.env` файл на основе `.env.exemple`:
```
TELEGRAM_BOT_TOKEN=ваш_токен_бота
```

## Архитектура

### Слоистая структура

```
bot.py (entry point)
    ↓
Controllers/ — обработка Telegram-событий
    ↓
Services/ — бизнес-логика
    ↓
Model/ — работа с БД (SQLite)
    ↓
Class/ — базовые классы (Model, Controller)
```

### Ключевые компоненты

**Class/** — базовые классы:
- `Model.py` — базовый класс для работы с SQLite (CRUD операции)
- `Controller.py` — базовый класс для Telegram-контроллеров

**Model/** — модели данных (наследуют `Model`):
- `Timer.py` — основные таймеры пользователей
- `SubTimer.py` — под-таймеры (детализация времени внутри таймера)
- `Session.py` — активные сессии (запущенные таймеры)
- `User.py` — пользователи

**Services/** — бизнес-логика:
- `TimerService.py` — основная логика таймеров (старт/стоп, статистика, клавиатура)
- `SubTimerService.py` — логика под-таймеров (создание, расчет времени)
- `FolderService.py` — управление режимами пользователя (normal/folder mode)
- `SubTimerRunnerService.py` — запуск/остановка под-таймеров
- `B24Service.py` — интеграция с Bitrix24 (не активна)
- `ReportService.py` — генерация отчетов

**Controllers/** — обработчики Telegram:
- `TimerController.py` — команды для таймеров (/new, /plus, /diff, /delete, кнопки старт/стоп)
- `SubTimerController.py` — создание под-таймеров через диалог
- `FolderController.py` — работа в режиме папки (запуск под-таймеров)
- `ReportController.py` — генерация отчетов

### Режимы работы

**Normal mode** — обычный режим:
- Показывает кнопки для запуска/остановки основных таймеров
- Таймеры с под-таймерами отображаются как папки (📁)

**Folder mode** — режим папки:
- Активируется при нажатии на таймер с под-таймерами
- Показывает кнопки для запуска под-таймеров
- Кнопка "🔙 Назад к таймерам" возвращает в normal mode

### Логика времени

**Основные таймеры:**
- Хранят общее время в `total_seconds`
- При остановке время сессии добавляется к `total_seconds`

**Под-таймеры:**
- Хранят свое время в `duration_seconds`
- При создании нового под-таймера автоматически рассчитывается его время: `время_таймера - сумма_существующих_подтаймеров`
- Время под-таймеров НЕ добавляется к родительскому таймеру (они детализируют уже существующее время)

**Сессии:**
- Активная сессия = запущенный таймер
- Может быть сессия основного таймера или под-таймера
- При остановке сохраняется `duration_seconds`

### Специальный таймер BabyTime

- Название: `👶 BabyTime`
- При запуске автоматически останавливает текущий активный таймер
- Создается с `timer_type=0` (пустой комментарий)
- Кнопка показывается только когда BabyTime не запущен

## Команды бота

**Команды:**
- `/start` — остановить все таймеры, показать справку
- `/new название id type` — создать таймер (type: 0='', 1='баги', 2='нкч', 3='кч')
- `/plus название минуты` — добавить время к таймеру
- `/plus родитель:подтаймер минуты` — добавить время к под-таймеру
- `/diff название минуты` — убавить время
- `/diff родитель:подтаймер минуты` — убавить время у под-таймера
- `/delete название` — удалить таймер

**Кнопки:**
- `▶️ Старт название` — запустить таймер
- `⏹️ Стоп название` — остановить таймер
- `📊 Статистика` — показать статистику за сегодня
- `📁 Создать под-таймер` — создать под-таймер для активного таймера
- `📁 название` — войти в режим папки (для таймеров с под-таймерами)
- `👶 BabyTime` — запустить специальный таймер

## База данных (SQLite)

**Файл:** `timers.db`

**Таблицы:**
- `timers` — основные таймеры (user_id, name, total_seconds, task_id, comment, created_at)
- `sub_timers` — под-таймеры (user_id, parent_timer_name, name, duration_seconds, created_at)
- `sessions` — сессии (user_id, timer_name, sub_timer_name, start_time, end_time, duration_seconds)
- `users` — пользователи

**Важно:** Все таймеры и под-таймеры привязаны к дате создания (`DATE(created_at) = DATE('now')`). Статистика показывается только за сегодня.

## Обработка сообщений

Единый обработчик `handle_all_messages()` в `bot.py`:

1. Проверка диалогов (awaiting_task_id, awaiting_comment, awaiting_sub_timer_name)
2. Обработка специальных кнопок (Статистика, BabyTime, Создать под-таймер)
3. Проверка режима пользователя (folder/normal)
4. Маршрутизация в соответствующий контроллер

## Паттерны кода

- Все Service методы используют инстансы (не статические)
- Controllers наследуют базовый `Controller` класс
- Models наследуют базовый `Model` класс с CRUD операциями
- Сообщения об ошибках на русском языке
- Используется `async/await` для Telegram handlers
- FolderService реализован как Singleton (хранит состояние пользователей в памяти)

## Интеграция с Bitrix24

`B24Service.py` содержит методы для работы с Bitrix24 API, но в текущей версии закомментированы:
- `refreshTokens()` — обновление токенов
- Методы для работы с задачами

## Важные детали

- При создании под-таймера родительский таймер должен быть активен (запущен)
- Нельзя запустить несколько таймеров одновременно
- При запуске под-таймера родительский таймер продолжает работать
- Статистика показывает активные таймеры с иконкой ⏳
- Время отображается в формате `Xh Ym` и `X.XXh`
